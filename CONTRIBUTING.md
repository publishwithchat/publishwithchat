# Contributing

This repository is the public home of Publish with chat: guides, brand assets and examples. The service itself is not open source.

## Helpful things to send

- **Corrections** to the guides: a step that no longer matches a chatbot's menus, a typo, something unclear.
- **Compatibility reports:** you tried another chatbot or plan and it worked, or did not. Use the "Chatbot report" issue form.
- **Prompt ideas** that gave you a good site. Add them to [docs/prompts.md](docs/prompts.md) with a pull request.
- **Bugs** in the connector or the service. Use the "Something is not working" issue form.

## How

1. For a small fix, open a pull request. For anything bigger, open an issue first so we can agree what it should be.
2. Keep to plain, friendly language. The guides are written for people who are not technical.
3. Do not include personal information, passwords or private links in issues or pull requests.

By sending a contribution you agree that we may use it in these guides.

Be kind. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
