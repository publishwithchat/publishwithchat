# Security

## Reporting a problem

If you find a security problem in Publish with chat, or in a site we host, please email support@publishwith.chat with "Security" in the subject. Include what you found, how to reproduce it and, if possible, which site or address is involved.

Please give us a reasonable chance to fix it before you share it publicly. We will acknowledge your message and keep you updated.

Do not test with other people's sites or accounts, and do not access or change data that is not yours.

## Harmful content

To report a site that breaks the law or our rules, use the report link on the site or preview itself, or email support@publishwith.chat. Reports about child sexual abuse material are acted on straight away.

## Scope

This repository holds public information only. The service itself is not open source, so there is no code here to audit.
